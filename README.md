# 🐄 QurbaniHat — Livestock Booking Platform

A modern livestock marketplace where users can explore animals for Qurbani such as cows and goats, view details, and place a booking after authentication.

---

## 🔗 Live URL

[https://b13-a8-three.vercel.app](https://b13-a8-three.vercel.app)

---

## ✨ Key Features

- 🐄 Browse livestock listings with sort by price (low to high / high to low)
- 🔍 View full animal details including breed, weight, age, and location
- 📋 Place a booking with a form (name, email, phone, address)
- 🔐 Authentication with email/password and Google OAuth (Better Auth)
- 👤 User profile page showing name, photo, and email
- ✏️ Update profile information (name and photo URL)
- 📱 Fully responsive — mobile, tablet, and desktop
- 🔔 Toast notifications for user actions
- 🚫 Custom 404 not-found pages
